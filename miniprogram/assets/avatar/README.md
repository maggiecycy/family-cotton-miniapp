# 虚拟女儿形象资源（路线 A：写实写真）

把下面 6 张图换成**你自己的照片 / 已授权 AI 写真**，文件名保持不变：

| 文件 | 表情 | 拍摄提示 |
|------|------|----------|
| idle.png | 默认 | 自然看着镜头，微微笑 |
| happy.png | 开心 | 更明显的笑 |
| miss.png | 想你 | 温柔、略带思念 |
| speak.png | 说话 | **微张嘴**或说话瞬间 |
| serious.png | 认真 | 平静、看着镜头 |
| sleepy.png | 困困 | 放松、轻微眯眼 |

## 统一要求（很重要）

- 同一发型、衣服系列、光线、背景
- 半身或肖像构图，脸部占比稳定
- 分辨率建议 ≥ 750×1000
- 不要每张换妆到认不出是同一个人

## 可用流程

1. 自拍 / 请人拍 6～10 张同场景不同表情  
2. 或用 AI 写真：同一张底图生成多表情，再人工筛选  
3. 导出 PNG，覆盖本目录同名文件  
4. 微信开发者工具重新编译
