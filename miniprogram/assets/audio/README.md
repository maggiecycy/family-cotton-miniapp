# 首页状态问候录音 · 台词稿

`greet-*.wav` 已被 `.gitignore`（本地录音不进 GitHub）。`demo-voice.wav` 可保留作占位。

## 怎么处理爸 / 妈？

- **不是两份时光轴数据**。一个家庭共用一套留言与心意。
- **文案和问候录音按观看者身份切换**：妈妈听到「妈…」，爸爸听到「爸…」。
- 文件：
  - 给妈妈：`greet-{状态}.wav`
  - 给爸爸：`greet-{状态}-dad.wav`（没有则暂时回退播妈妈版）

先录妈妈版 9 条就够演示；爸爸版有空再补。

## 录制建议

1. 手机录音，尽量安静；每条 3～15 秒  
2. 导出 **wav** 或 **mp3**（若用 mp3，改后缀并改 `utils/homeState.js` 里路径）  
3. 覆盖 `miniprogram/assets/audio/` 同名文件  
4. 重新编译小程序  

首页：点图片 / 问候文字 = 播当前状态录音；「换表情」只换照片。
