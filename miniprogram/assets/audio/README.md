# 首页状态问候录音 · 台词稿

`greet-*.{m4a,wav,mp3}` 已被 `.gitignore`（本地录音不进 GitHub）。`demo-voice.m4a` 可作时光轴占位。

## 体积限制（微信代码质量）

- **单文件**：图片 / 音频均须 **< 200KB**
- **主包**：整包须 **< 1.5MB**（首页 tab 在主包，素材会计入主包）
- **推荐格式**：`m4a`（AAC，约 32–64kbps，单声道）——比 wav 小很多
- **时长**：每条约 3～12 秒；真录音后若主包又超限，改为云存储 `fileID` 再播放

示例压缩：

```bash
ffmpeg -i input.wav -c:a aac -b:a 48k -ac 1 -ar 16000 greet-idle.m4a
```

## 怎么处理爸 / 妈？

- **不是两份时光轴数据**。一个家庭共用一套留言与心意。
- **文案和问候录音按观看者身份切换**：妈妈听到「妈…」，爸爸听到「爸…」。
- 文件：
  - 给妈妈：`greet-{状态}.m4a`
  - 给爸爸：`greet-{状态}-dad.m4a`（没有则暂时回退播妈妈版）

先录妈妈版 9 条就够演示；爸爸版有空再补。

## 录制建议

1. 手机录音，尽量安静；每条 3～15 秒  
2. 导出 **m4a**（推荐）或 mp3；若仍用 wav，请降采样并确保单文件 < 200KB，且主包不超 1.5MB  
3. 覆盖 `miniprogram/assets/audio/` 同名文件（路径见 `utils/homeState.js`）  
4. 开发者工具 → 重新编译 → 详情 → 代码质量  

首页：点图片 / 问候文字 = 播当前状态录音；「换表情」只换照片。
