# 首页状态问候录音 · 台词稿

`greet-*.{m4a,wav,mp3}` 已被 `.gitignore`（本地录音不进 GitHub）。

## 6 种状态（仅录妈妈版）

| 文件 | 状态 | 请对着手机说（约 5～12 秒） |
|------|------|---------------------------|
| greet-idle.m4a | 默认 | 妈，我在呢。今天也要开心一点。 |
| greet-happy.m4a | 开心 | 妈，想到你我就想笑。今天也要对你好好的。 |
| greet-miss.m4a | 想你 | 妈，有点想你了。别担心，我过得很好，也很爱你。 |
| greet-soft.m4a | 温柔 | 妈，慢慢来就好，累了就休息。我一直在。 |
| greet-tender.m4a | 贴心 | 妈，记得吃饭、喝温水。你开心，我就安心。 |
| greet-speak.m4a | 说话 | 妈，我想跟你说：你值得被好好照顾。 |

爸爸打开时：**文案**自动改成「爸…」，**录音仍播以上妈妈版**（不必另录 `-dad` 文件）。

## 体积限制

- 单文件 **< 200KB**；主包整包 **< 1.5MB**
- 推荐 `m4a`（AAC 48kbps 单声道）

```bash
ffmpeg -i input.wav -c:a aac -b:a 48k -ac 1 -ar 16000 greet-idle.m4a
```

覆盖到 `miniprogram/assets/audio/` 后，开发者工具重新编译。
