# 用户隐私保护说明（配置到公众平台时对照）

本小程序「云端小棉袄」为家庭陪伴工具。涉及的用户信息与用途如下：

| 信息类型 | 使用场景 | 用途 |
|----------|----------|------|
| **麦克风（录音）** | 女儿发语音留言 | 仅用于录制并上传家庭语音，不会用于其他用途 |
| **相册 / 相机（选图）** | 家长上传照片墙 | 选择本地或拍摄照片上传至家庭相册 |
| **写入相册** | 保存女儿写真 | 用户主动点击「保存到相册」时写入手机相册 |
| **云开发存储** | 语音、照片、纸条 | 仅家庭成员可读，用于时光轴展示 |
| **剪贴板** | 复制邀请码 | 方便把邀请码发给家人 |

**不采集：** 精确位置、手机号、通讯录、通讯记录、身份证等。

**存储与共享：** 数据保存在微信云开发环境，仅绑定同一家庭邀请码的成员可见；不向第三方出售。

## 公众平台必做（否则录音 errno 112）

官方入口（二选一，常见是入口 A）：

### 入口 A：账号设置里完善（现网隐私指引）

你现在已经在 **管理 → 账号设置** 了，但别停在「隐私与安全」那几行开关。

1. 在 **账号设置** 这一页 **继续往下滚**
2. 找到板块 **「服务内容声明」**（不在左侧菜单，在右侧内容区）
3. 里面有 **「用户隐私保护指引」** → 点 **「去完善」/「更新」**
4. 勾选并填写用途说明，例如：
   - **麦克风** → 用于女儿录制语音留言给家人收听
   - **选中的照片或视频 / 相册** → 用于家长上传家庭照片墙
   - **相册（仅写入）权限** → 用于用户主动保存写真到手机相册
5. 填完 **提交**；若需审核，等通过后再测录音

### 入口 B：提审时拦截（开发版隐私指引）

**管理 → 版本管理 → 提交代码审核** 的信息填写页里，若提示隐私指引缺失，点「去完善」。

### 若整页都找不到「服务内容声明」

- 左侧再往下找独立菜单 **「设置」**（和「管理」同级）→ **基本设置 / 功能设置** → **用户隐私保护指引**
- 确认登录的是 **小程序管理员** 账号（开发者成员有时看不到完整设置）
- 直接打开文档对照：https://developers.weixin.qq.com/miniprogram/dev/framework/user-privacy/

未声明时会出现：

- 控制台：`start:fail api scope is not declared in the privacy agreement`（errno 112）
- 「去开启」打开设置页，只显示「允许…使用我的」后面空白——因为平台侧没有可授权的隐私项

代码侧已配置：

- `app.json` → `permission.scope.record` / `permission.scope.writePhotosAlbum`
- `app.json` → `__usePrivacyCheck__: true`（基础库隐私弹窗）
- 录音前 `wx.requirePrivacyAuthorize`；被拒时引导 `wx.openSetting`
