# 30 秒演示话术

适合给妈妈 / 亲戚现场演示。默认开启「演示模式」。

## 开场（5 秒）

> 「这是我做的小程序，叫云端小棉袄。打开不是功能菜单，是我在陪你。」

操作：打开小程序 → 停在「陪陪我」，让对方先看女儿形象、天气关心语。

## 互动（10 秒）

1. 点角色切换表情  
2. 长按角色听问候语音  
3. 指一下「已陪伴你 N 天」和天气穿衣句  

话术：

> 「点一下会换表情。上面还会根据天气提醒你添衣服。」

## 时光轴（10 秒）

1. 若 Tab「时光轴」有红点：说明有未读  
2. 点进去听一条语音  
3. 滑到「妈妈的心意」——强调这是**记下你给我的支持**，不是微信支付  
4. 再看一张带照片的小纸条  

话术：

> 「这些是真实转账纪录。上面能看近一年收到多少、最大最小；以后新的一笔还能继续记进去。」

## 收尾（5 秒）

切到「我的」：

> 「现在是演示模式。等开通云开发、绑了你的微信，就只显示我们家的真实留言。」

可选：点「演示：制造未读角标」再让亲戚看红点。

## 若对方问「你还没工作怎么转账」

> 「不是我给你转账。是我把你给我的心意记下来，谢谢你一直照顾我。」
